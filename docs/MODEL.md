# 程序图格式

`scar.graph-bundle` v3 使用区域、操作、边和资源表。区域可以包含更小的区域，函数、循环和分支都可以保留结构。操作有稳定的所属区域，输入输出记录值的标识，数据边记录值流关系，控制和回边记录时序约束，资源边记录硬件连通关系。外部输入和未解决的调用依赖通过端口及证据表达。

同一个操作可以同时产生值、修改状态并调用外部资源，其效果由列表描述。未知的字段或未取得的证据保留缺口。图的文件引用记录绝对路径、字节数和 SHA-256，读者通过共同合同验证。

`scar.compiler-plan` v3 记录前端图收据、改写、资源、时序约束和可执行 IR。每个排程步骤记录操作、资源、前置约束和可用的时间信息。封存的可执行体可以是结构化逐元素计算，也可以是有 ABI 的片段模块。后端通过计划包的相对收据取得这些内容。当前 CPU 试验保留未知时长，正式部署以完整的成本和正确性证据为准。
